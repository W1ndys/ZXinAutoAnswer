# ZXinAutoAnswer

【子仓库】知新平台自动做题脚本，主仓库 [ZXinTools](https://github.com/W1ndys/ZXinTools)

已实现爆破单选题、判断题、多选题提交并返回答案

暂不开源，仅供学习交流使用

开源的时候记得删库重开，有账号密码泄漏风险
